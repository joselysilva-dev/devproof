# Demonstração — até 3 minutos

Antes: iniciar API e frontend; escolher PR público; preparar Phantom em devnet com SOL de teste. Ensaiar a assinatura com o colaborador. Não chamar a confirmação de identidade GitHub.

- **0:00–0:30:** “O DevProof reúne uma entrega pública, uma declaração e uma confirmação pelo titular de uma carteira.” Mostrar a tela e explicar que é um protótipo.
- **0:30–1:00:** Colar PR real, consultar e mostrar título, autor, repositório e SHA. Explicar snapshot do código entregue.
- **1:00–1:25:** Criar declaração. Mostrar ID, hash e link para compartilhar.
- **1:25–2:00:** Colaborador abre o link, conecta Phantom e assina. Mostrar mudança para confirmado por carteira. “Não verificamos a identidade GitHub dessa pessoa.”
- **2:00–2:35:** Registrar hash na devnet com a mesma carteira. Mostrar solicitação Memo e taxa em SOL de teste. Aguardar confirmação da API. Se pendente, dizer “aguardando registro” e usar verificar transação enviada; não anunciar sucesso antes da validação.
- **2:35–3:00:** Abrir explorador devnet e verificar integridade pelo aplicativo. Explicar que a rede guarda somente hash, e SQLite guarda conteúdo e assinatura.

Se carteira/RPC não estiver disponível: mostrar os estados já existentes com sua situação real, explicar a pendência e apresentar os testes automatizados como testes controlados, sem fingir registro on-chain. Uma gravação prévia só pode ser usada se for real e identificada como gravação.
